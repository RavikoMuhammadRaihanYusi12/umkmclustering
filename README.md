# Identifikasi Kelayakan Strategi Bisnis Berdasarkan Sebaran UMKM Menggunakan K-Means Clustering

## 📄 Ringkasan Proyek

Penelitian ini menerapkan teknik *Data Mining* menggunakan algoritma **K-Means Clustering** untuk menganalisis dan mengelompokkan pola sebaran UMKM berdasarkan variabel operasional serta karakteristik spasial wilayah. Hasil dari pengelompokan ini digunakan untuk mengidentifikasi potensi daerah dan menentukan kelayakan serta pemetaan rekomendasi strategi bisnis yang presisi dan tepat sasaran bagi pemangku kepentingan maupun pelaku usaha.

---

## 🛠️ Metodologi & Fitur Utama

- **Data Preprocessing & Cleaning**: Pembersihan data, penanganan *missing values*, serta transformasi data agar siap diolah.
- **Normalisasi Data**: Penggunaan skala standar (seperti *MinMaxScaler* atau *StandardScaler*) untuk menyetarakan bobot antar variabel/fitur.
- **K-Means Clustering**: Pengelompokan data sebaran UMKM ke dalam klaster berbasis karakteristik dan potensi wilayah.
- **Evaluasi Optimalisasi Klaster**: Penentuan jumlah klaster optimal ($k$) menggunakan *Elbow Method* dan evaluasi kualitas klaster dengan *Silhouette Score*.
- **Analisis Strategi Bisnis**: Interpretasi profil tiap klaster untuk merumuskan rekomendasi strategi bisnis yang aplikatif.
